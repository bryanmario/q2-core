# Q2-Core

Q2-Core is a music-first, reimagined firmware overhaul for the Shanling Q2, based on the popular Q2-Pod platform and built around your offline listening experience.

**Everything you want, nothing you don't.**

True to its name, Q2-Core strips away distractions to keep only essential audio functionality. All core features, including wheel navigation, CoverFlow, parametric EQ, and full audio settings, remain intact, while extras like e-books, games, and streaming are removed to keep the focus purely on browsing, playing, and tuning your music library.

> **Disclaimer:** This is a personal project tailored to my own preferences, forked from the amazing work done by [DiamondBond/q2-pod](https://github.com/DiamondBond/q2-pod). Future updates to this edition will only track stable releases of the q2-pod platform, maintaining feature parity only for core player functionality while keeping non-music extras stripped out.
